# USB sound-card mode

Reserved for the standalone V2 USB release. Sources and Firmware folders will
be populated in the next publication step; no USB V2 download is provided yet.

The intended experience is a 48 kHz mono processed microphone, speaker playback,
automatic array selection, gesture mute, volume buttons and internal/external
speaker selection. Do not use Pi firmware for USB sound-card operation or
older main-branch images for V2 hardware.
