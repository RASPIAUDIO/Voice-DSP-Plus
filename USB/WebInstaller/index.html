1. Choose USB or I2S firmware

V2 and V1 firmware are not interchangeable. Normal installation checks the VDSP2-USBMONO USB identity. Force mode bypasses this check. A blank board or an I2S-only board needs USB Recovery or SPI provisioning before using this updater. V2 installation and recovery guide

I2S is not a USB sound card. A host must configure I2S audio. With Safe Mode installed, use the five-second USB recovery window to switch back to USB. Older boards without Safe Mode need the ZeroCore Safe Recovery installer linked above first.

2. Connect Voice DSP+

Stop all audio playback and close audio/control apps. Connect the XMOS USB data port, keep it powered during the update, then choose the XMOS device in the browser picker.
